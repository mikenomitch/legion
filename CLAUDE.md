# CLAUDE.md

Legion's repository guidelines live in [AGENTS.md](AGENTS.md) — one file, so the
instructions never drift between tools. It is imported below; read it before
making changes.

Two rules are easy to miss and are not optional:

- **All new features must be well documented** in `docs/` (public).
- **Non-trivial features record their judgement calls** in
  `internal_docs/calls/<plan-name>_calls.md` (internal).
